# Editing the images ready for the website

1. move the fresh images into the `./to-process/` dir.
1. Give image a reasonable name
1. Open image in GIMP
1. Crop if necessary using the 'fixed aspect ratio' mode and overwrite file
1. Resize image to be 800px in it's longest dimension
1. Use draw pad and paintbrush tool to draw initials. Settings are as follows:
    * mode: multiply
    * opacity: 100%
    * colour: #c96516
    * size: 10px
    * hardness: 100%
    * spacing: 10
    * force: 69
1. Export image to `./website/imgs/35mm/` as a `.webp` file
1. Move file out of `./to-process/` into `./originals/`
